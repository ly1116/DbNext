# DataRoost v0.2 路线图（下一版本要干的事）

> 对标参照：**DBeaver / Navicat Premium**（数据库客户端能力）、**XTerminal / SecureCRT**（SSH 终端与文件能力）。  
> 基线版本：**v0.1.1**（已含：跨方言数据传输、表清单元数据、选中自动连接、传输带注释/索引/外键、存储过程分类+右键新建、SSH 隧道、SQL 编辑器+自动补全骨架、数据网格、Redis、SFTP 全屏、终端面板、结构对比、AI 侧栏）。  
> 编号规则：`V2-<模块>-<序号>`；优先级 `P0 必做 / P1 重要 / P2 增强`；工作量 `S 小 / M 中 / L 大`。

## 建议的 v0.2 发布范围（聚焦高价值）

**必做（P0，构成 v0.2 核心）**

- SQL：V2-SQL-01/02/04（补全、格式化、执行计划）
- 导入导出：V2-IO-01/02（导出、导入向导）
- 对象：V2-OBJ-01/05（触发器、可视化表设计器）
- 安全：V2-SEC-01（危险操作守卫）

**重要（P1，尽量纳入）**

- SQL 历史/事务/片段；整库转储；事件/包/序列；索引/外键 UI；生成脚本；信息面板
- 数据对比 Data Diff + 结构同步执行；SSH 端口转发/分屏/SFTP 增强
- 环境着色、凭据加密；全局搜索；虚拟滚动；BLOB 查看器

**增强（P2，排期到 v0.2.x 或 v0.3）**

- 图表、ER 图、模拟数据、监控、审计、密钥管理、主题/快捷键、自动更新等。

## 进度跟踪（2026-10-03 已落地）

- ✅ **V2-SQL-01 智能补全（基础）**：SQL 编辑器整体换用 CodeMirror（`workbench/SqlEditor`），接 `api.listSchemaColumns` 拉取「表→列」元数据驱动补全（跨库感知）；`sql-completion.ts` 追加函数库 + 参数提示（detail 签名）。
- ✅ **V2-SQL-02 SQL 格式化**：工具栏「格式化」按钮，复用 sql-formatter（keywordCase upper / tabWidth 2），优先格式化选中文本。
- ✅ **V2-SQL-04 执行计划可视化**：MySQL 扫描类型彩色徽章 + 全表扫描告警；PG `EXPLAIN (FORMAT JSON)` 解析为缩进计划树；Oracle 回退 DataGrid。
- 🔧 附带：运行选中 / 保存脚本 / Navicat 风格可展开对象树 / 轻量危险操作守卫（DROP·TRUNCATE·无 WHERE 的 DELETE/UPDATE 二次确认）。
- ⏳ 仍待续：V2-SQL-03 多标签多结果集、V2-SQL-05 查询历史持久化、V2-SQL-06 事务控制、V2-SQL-07 结果图表、V2-SQL-08 片段库。
