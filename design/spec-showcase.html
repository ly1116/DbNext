02

09

设计红线速查

以下 15 组是验收时的硬性检查项。左侧为唯一正确做法，右侧为明确禁止 —— 出现任一「Don't」即视为缺陷，需返工而非讨论。

Do · 正确做法
Don't · 禁止
01用 6px 状态点 + 灰色文字表达「启用 / 停用」
01用绿色 / 红色胶囊标签写「启用」
02分区靠 1px #F1F1F1 细线划分
02用彩色左侧竖条、卡片投影、色块分区
03主按钮用近黑实底（#18181B），一屏一个
03用蓝 / 紫渐变按钮，或满屏都是实底按钮
04圆角最大 10px，按钮 / 输入 5px
04用 12–16px 大圆角、半圆胶囊按钮
05阴影只给浮层，且极弱
05给卡片、按钮、hover 行加阴影做「浮起」
06图标用 Lucide 线性 1.8 线宽，继承文字色
06用 emoji 当图标、彩色图标、图标加渐变圆底
07表格用固定表头 + 单行省略号 + hover 全文
07用斑马纹、竖线分栏、行间大留白
08数字 / 时间 / ID 用 tabular-nums 等宽
08表格里时间左右参差、数字用比例字体
09元信息用 10–11px 灰字，字号阶梯收敛为整数档
09用 9px 以下字号、或一屏出现 5 种以上字号
10批量操作在工具行原位替换（高度不变 44）
10弹一条浮动的蓝色批量操作条遮住内容
11空状态说明「下一步做什么」+ 一个按钮
11只放一个灰字「暂无数据」
12危险操作按 L1 / L2 / L3 分级加摩擦
12所有删除都弹窗，或都不弹窗
13生产环境用灰色 prod 标签 + 文案提示
13顶栏常驻红色横幅 / 红色边框（红色疲劳）
14悬停只改背景色（120ms）
14悬停放大、位移、发光、光标变手型
15选中行靠底色 + 左侧 2px 黑条
15选中行用蓝色高亮 + 白色文字

注：上表的绿勾 / 红叉仅用于本文档的标注语义，不属于产品界面配色； 界面内 success / danger 仅按 §5.2 允许位置使用。
