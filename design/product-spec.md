# DbNest 产品设计规范

> 版本 v1.0 ｜ 产品：许清楚 ｜ 适用范围：`dbnest-modern.html` 视觉方向已定稿的桌面端主界面
> 本文是**裁决文档**：后续任何界面分歧以此为准；本文未覆盖的场景，按「产品原则」推导后回写本文。

---

## 1. 产品定位

### 1.1 一句话定位

**面向研发团队的跨平台数据库工作台：用三个常驻栏位完成「连接 → 浏览 → 治理」，视觉上不占用任何一像素给装饰。**

### 1.2 目标用户画像

| 画像 | 角色特征 | 典型场景 | 核心痛点 | 对设计的隐含要求 |
|---|---|---|---|---|
| **A. 业务后端开发**（主力，占比约 60%） | 25–35 岁，每天在 3–6 个库之间切换，日均 20–40 次查询 | 排查线上数据、比对生产/测试库差异、临时改一条记录 | 切库路径长、找表靠翻树、GUI 装饰挤占屏幕 | 树要窄、列表要密、键盘要能走完全流程 |
| **B. DBA / 平台运维**（占比约 25%） | 30–45 岁，对权限与审计负最终责任 | 新建账户并授权、离职批量停用、追查某账户的异常操作 | 权限变更无留痕、批量操作易误伤、生产环境误操作成本高 | 权限必须可逐项开关且可回滚；危险操作必须加摩擦 |
| **C. 数据分析 / 运营**（占比约 15%） | 25–32 岁，SQL 能力弱，以只读+导出为主 | 导出某段时间的订单、按条件筛表、看字段含义 | 不会写 SQL、导出入口藏得深、看不懂字段类型 | 表格能纯鼠标筛选；字段类型与含义常驻可见 |

### 1.3 与竞品的差异化取向

| 竞品 | 它强在哪 | 它牺牲了什么 | DbNest 的取舍 |
|---|---|---|---|
| **TablePlus** | 启动快、原生控件手感、查询体验干脆 | 团队治理几乎为零（无账户/权限/审计概念）；界面停留在 2016 年审美 | 保留它的「快」与「密」，补上治理模块，重做视觉 |
| **Beekeeper Studio** | 开源、上手门槛低、跨库一致性好 | 功能浅（无会话管理、无审计）；彩色标签与图标堆叠，长时间使用疲劳 | 拒绝彩色语义堆叠，用单色 + 状态点表达同等信息 |
| **DataGrip** | IDE 级能力：重构、索引建议、全库检索 | 重（冷启动 10s+）、学习曲线陡、面板多到需要记忆 | 只做日常 80% 高频操作；低频能力收进命令面板而非铺在界面上 |

**差异化的三句话**：比 TablePlus 多一层团队治理；比 Beekeeper 少一层视觉噪音；比 DataGrip 少一层功能负担。

### 1.4 产品原则（用于裁决一切设计分歧）

| # | 原则 | 可执行的判定标准 |
|---|---|---|
| P1 | **信息先于装饰** | 任何像素若删掉后不损失信息与可点击性，则删掉。禁止：渐变、装饰性插画、图标徽标底、大数字指标卡 |
| P2 | **单色承载层级，颜色只承载状态** | 界面 95% 面积只允许出现中性灰阶。彩色仅允许出现在：状态点（6px 圆点）、危险按钮、校验错误文案 |
| P3 | **三栏常驻，零页面跳转** | 列表 → 详情必须在同屏完成。任何「点进去再返回」的路径视为设计缺陷，应改为右栏展开或抽屉 |
| P4 | **键盘与鼠标等价** | 每一个鼠标可达的操作，都必须有快捷键或在命令面板中可检索到。新增功能未定义快捷键则不予验收 |
| P5 | **破坏性操作必须有摩擦，且可回退** | 按 §7.5 分级执行；未分级的危险操作视为缺陷 |

## 2. 核心任务流

### 2.1 主路径（冷启动 → 可操作）

| 步 | 用户动作 | 界面区域 | 系统响应 | 时延预算 |
|---|---|---|---|---|
| 1 | 启动应用 | — | 恢复上次连接与上次选中的一级导航、选中行 | ≤ 1.2s 出现骨架屏 |
| 2 | 观察连接状态 | 顶栏连接切换器 · 状态栏 | 连接点变绿 + 状态栏显示 `已连接 · 延迟 12ms · PG 16.2` | 连接 ≤ 2s，超时降级为「重试」文案 |
| 3 | 展开连接 | 左栏连接树 | 惰性加载库 → 表，展开箭头旋转 160ms | 每层 ≤ 300ms |
| 4 | 点选节点 | 左栏树 | 中栏切换到对应列表（用户/数据表/…），页头计数更新 | 立即（< 100ms，先渲染骨架） |
| 5 | 点选某一行 | 中栏表格 | 该行 `selected`，右栏 Inspector 渲染该条详情 | 立即 |
| 6 | 执行操作 | 右栏底栏 / 顶栏主操作 | Toast 或内联错误 | 见 §7.4 |

> 关键约束：第 4、5 步都不改变左栏与顶栏状态 —— 用户永远知道自己「在哪」。

### 2.2 高频任务流

**T1 · 新建数据库账户并授权（最高频管理动作）**

| 步 | 动作 | 区域 | 细节 |
|---|---|---|---|
| 1 | ⌘N 或点顶栏「新建用户」 | 顶栏主操作 | 触发主操作的上下文由当前一级导航决定 |
| 2 | 填写用户名 / 邮箱 / 角色 | 对话框（480px，居中） | 用户名失焦即校验重名，错误内联在字段下方 |
| 3 | 提交 | 对话框底栏 | 主按钮 loading 态（文案不变，左侧 12px 环形） |
| 4 | 保存后自动选中新行 | 中栏 + 右栏 | 新行短暂 600ms 高亮底 `#FAFAFA` 后回落 |
| 5 | 逐项打开权限开关 | 右栏 Inspector 权限分区 | 开关即时生效但**不提交**，底栏「保存」变为可用 |
| 6 | 点保存 | 右栏底栏 | 底栏显示未保存标记（标题后 4px 圆点），成功后 Toast「已保存」 |

**T2 · 定位并查看一张表的数据**

| 步 | 动作 | 区域 |
|---|---|---|
| 1 | ⌘K 打开命令面板，输入表名 | 浮层命令面板（居中，560px） |
| 2 | Enter 打开 | 中栏切换为数据网格，页头显示 `表名 · 行数` |
| 3 | 读数据 | 中栏网格（表头 32px 固定，行高 30px） |
| 4 | 点行查看字段定义 | 右栏 Tabs：字段 / 索引 / 外键 |
| 5 | 复制单元格 | ⌘⇧C，Toast「已复制」 |

**T3 · 追查某账户的异常操作**

| 步 | 动作 | 区域 |
|---|---|---|
| 1 | 点左栏一级导航「审计」 | 左栏 → 中栏 |
| 2 | 工具行输入账户名 + 时间范围 | 中栏工具行 |
| 3 | 点某条日志 | 中栏行 |
| 4 | 阅读上下文 | 右栏：操作类型 / 目标对象 / 来源 IP / SQL 原文（等宽可复制） |
| 5 | 跳转到该账户 | 右栏「查看账户」→ 中栏切到用户列表并选中该行 |

**T4 · 切换环境执行临时查询**

| 步 | 动作 | 区域 |
|---|---|---|
| 1 | 点顶栏连接切换器 | 顶栏 → 下拉（320px） |
| 2 | 选中目标连接 | 下拉项，左侧状态点 |
| 3 | 若为生产环境 | 切换器右侧出现中性描边标签 `prod`（非红色，见 §7.5） |
| 4 | 输入 SQL | 中栏查询区（等宽 12px） |
| 5 | ⌘Enter 执行 | 结果表格替代查询区下半部，状态栏显示行数与耗时 |

**T5 · 批量停用离职账户**

| 步 | 动作 | 区域 |
|---|---|---|
| 1 | 表格行首 Checkbox 多选 | 中栏表格 |
| 2 | 选中 ≥1 行后出现批量工具条 | 工具行原位替换（不新增浮层），高度不变 44px |
| 3 | 点「停用」 | 批量工具条 |
| 4 | 二次确认：`将停用 3 个账户` + 列出账户名 | 对话框（L2 级） |
| 5 | 确认后 Toast 带「撤销」5s | 右下角 Toast |

## 3. 信息架构（IA）

### 3.1 层级树

```
应用窗口
├── 顶栏 Topbar（50px，常驻）
│   ├── 品牌区：Logo 标记 + 产品名
│   ├── 连接切换器（当前连接 + 状态点 + 版本）→ 下拉浮层
│   └── 右侧：全局搜索（点击 = ⌘K）/ 主操作按钮 / 更多菜单
├── 主体三栏（flex，占满剩余高度）
│   ├── 左栏 Rail（214px，常驻，可折叠）
│   │   ├── 一级导航（用户 / 数据表 / 会话 / 审计）— 互斥单选
│   │   ├── 连接区（分组标题 + 连接树：连接 → 库 → 表）
│   │   └── 页脚（版本号）
│   ├── 中栏 Content（flex，min-width 480）
│   │   ├── 页头（标题 + 计数 + 刷新 + 视图切换）
│   │   ├── 工具行（筛选输入 + 分段控件 / 批量操作条）
│   │   └── 内容区（表格 / 数据网格 / 查询编辑器 / 空态）
│   └── 右栏 Inspector（322px，随选中态出现，可关闭）
│       ├── 头部（对象标识 + 标签 + 关闭）
│       ├── 滚动区（分区：属性 / 权限 / 关联 / 最近活动）
│       └── 底栏（次要操作 + 主要操作，常驻不滚动）
└── 状态栏 Statusbar（26px，常驻）：连接 / 延迟 / 版本 / 右对齐就绪态
```

### 3.2 职责边界（越界即缺陷）

| 区域 | 只负责 | 明确禁止 |
|---|---|---|
| 左栏 | **定位**：我在哪个库、哪个模块、哪个对象 | 不放行内编辑、不放详情、不放主操作（唯一例外：区块标题右侧 `+`） |
| 中栏 | **集合**：一族对象的浏览、筛选、排序、批量选择 | 不放单条记录的完整详情；不放跨对象导航 |
| 右栏 | **单条**：一个对象的属性、编辑、单条动作 | 不做列表；不做全局搜索；宽度内不嵌套第三层导航 |
| 顶栏 | **全局**：身份（品牌）、环境（连接）、检索（⌘K）、当前模块主操作 | 不放模块内筛选；不放分页 |
| 状态栏 | **系统事实**：连接健康、延迟、版本、就绪/忙碌 | 不放可点击操作（延迟可点开诊断弹层为唯一例外） |

### 3.3 常驻 vs 浮层

| 形态 | 承载内容 | 尺寸规则 | 触发/关闭 |
|---|---|---|---|
| **常驻** | 顶栏、左栏、中栏、右栏、状态栏 | 见 §4 | 始终可见 |
| **抽屉 Drawer** | 窄屏下的 Inspector、SFTP/终端类辅助面板 | 宽 360px，右侧滑入 | Esc / 点遮罩；160ms |
| **对话框 Dialog** | 新建/编辑表单、二次确认、设置面板 | S 480 / M 640 / L 800（设置面板） | Esc / 取消；焦点捕获 |
| **命令面板** | 全局检索与动作执行 | 560×最大 420，居中偏上（top 15vh） | ⌘K 开关；Esc |
| **下拉菜单** | 连接切换、行操作、列头菜单 | 最小 180，最大 320 | 点击外部 / Esc |
| **Toast** | 操作结果、撤销入口 | 320×auto，右下 16px | 3s 自动（带撤销则 5s） |
| **Tooltip** | 图标按钮释义、快捷键提示 | 最大 240 | hover 400ms 延迟 |

## 4. 布局规范

### 4.1 窗口

| 项 | 值 |
|---|---|
| 最小尺寸 | 1100 × 720 |
| 推荐/默认尺寸 | 1440 × 900 |
| 首次启动位置 | 屏幕居中，记住上次尺寸与位置 |
| 全屏支持 | 是（macOS 原生全屏 / Windows 最大化） |
| 内容最大宽度 | 不限制，表格随窗口拉伸 |

### 4.2 三栏宽度与折叠

| 栏 | 默认 | 最小 | 最大 | 弹性 | 折叠方式 |
|---|---|---|---|---|---|
| 左栏 Rail | 214 | 180 | 260 | 固定（可拖拽调宽，步长 1px，记忆） | ⌘B 折叠为 0（完全隐藏，非图标栏） |
| 中栏 Content | flex 撑满 | 480 | — | 弹性 | 永不折叠 |
| 右栏 Inspector | 322 | 280 | 360 | 固定（可拖拽） | ⌘\ 或点关闭；无选中时自动隐去 |

**响应式断点**

| 窗口宽度 | 生效规则 |
|---|---|
| ≥ 1440 | Rail 214 + Inspector 322，左右均可拖拽 |
| 1280 – 1439 | Rail 214 + Inspector 300 |
| 1100 – 1279 | Rail 200 + Inspector 280；工具行超出部分收入「更多」下拉 |
| < 1100 | 不允许（触发最小尺寸约束）；若被系统强制缩小，Inspector 降级为右侧抽屉 360 |

### 4.3 垂直分区高度

| 分区 | 高度 | 分隔 |
|---|---|---|
| 顶栏 | 50 | 下边框 1px `line` |
| 中栏页头 | 46 | 下边框 1px `line` |
| 工具行（筛选/批量） | 44（内 padding 8 + 控件 28） | 下边框 1px `line` |
| 表头 | 32（sticky） | 下边框 1px `line` |
| 列表行（双行主副文本） | 50 | 行间 1px `line-soft` |
| 列表行（单行） | 36 | 行间 1px `line-soft` |
| 数据网格行 | 30（默认）/ 26（紧凑） | 行间 1px `line-soft` |
| 右栏头部 | 自适应（padding 14，约 92–110） | 下边框 1px `line` |
| 右栏分区 | padding 12 14 | 区间 1px `line-soft` |
| 右栏底栏 | 自适应（padding 9 14，约 48） | 上边框 1px `line` |
| 状态栏 | 26 | 上边框 1px `line` |

### 4.4 内边距与分隔线

| 场景 | 值 |
|---|---|
| 栏内水平基准 | 左栏 7（导航项内 8）｜中栏 14（表格单元格 12）｜右栏 14 |
| 控件到容器边 | 顶栏 12｜工具行 10｜页头 14 |
| **主分隔线**（区块级） | 1px `line #E8E8E8`：顶栏、页头、工具行、表头、右栏头/底栏、状态栏、栏间 |
| **次级分隔线**（条目级） | 1px `line-soft #F1F1F1`：表格行间、Inspector 分区之间、权限项之间 |
| 禁止 | 2px 及以上的分隔线；双线；分隔线 + 阴影并用 |

## 5. 设计语言（Design Tokens）

### 5.1 中性色阶（Light）

| Token | HEX | 语义名 | 典型用途 |
|---|---|---|---|
| `n0` | `#FFFFFF` | 画布 | 中栏/右栏底色、按钮默认底 |
| `n1` | `#FCFCFC` | 浅面 | 表头底、Inspector 底栏底 |
| `n2` | `#FAFAFA` | 次级面 | 左栏底、状态栏底、Tag 默认底 |
| `n3` | `#F4F4F5` | 悬停面 | 行悬停、选中行底、按钮 hover |
| `n4` | `#EFEFF1` | 实心浅灰 | 树/导航 hover、头像块底、Tag 实心底 |
| `n5` | `#E8E8E8` | 主边框 | 结构分隔线、输入框边框 |
| `n6` | `#E2E2E4` | 强边框 | Tag 实心描边、开关轨道 |
| `n7` | `#C5C5C9` | 禁用文字 | 停用状态点、disabled 文本 |
| `n8` | `#A8A8B0` | 四级文字 | 占位符、元信息、kbd、计数 |
| `n9` | `#8E8E96` | 三级文字 | 分区标题、KV 的 key、Tag 文字 |
| `n10` | `#52525B` | 二级文字 | 表格正文、导航默认文字 |
| `n11` | `#18181B` | 一级文字 / 强调 | 标题、主按钮底、品牌标记、选中行左标 |

### 5.2 语义色

| Token | 值 | 允许出现的位置 | 禁止 |
|---|---|---|---|
| `success` 点 | `#16A34A` | 仅 6px 状态点、连接点 | 文字、背景块、边框 |
| `success` 文 | `#15803D` | 仅「启用」等状态文字（可与点同现） | 大面积背景 |
| `warning` 点 | `#D97706` | 6px 点：连接降级、延迟 > 300ms | 徽标、按钮 |
| `warning` 文 | `#B45309` | 内联警告文案 | 常态信息 |
| `danger` 点 | `#DC2626` | 6px 点：连接失败、错误 | — |
| `danger` 文 | `#B91C1C` | 校验错误文案、危险按钮文字 | 普通文字 |
| `danger` 实底 | `#DC2626` | 仅 L3 级危险确认对话框的主按钮 | 工具栏、列表 |
| `info` | **不设独立色** | 用 `n10` + 链接下划线表达 | 蓝色信息条、蓝色徽标 |

> **强调色规则**：强调色 = `accent`，Light 为 `n11 #18181B`，Dark 为 `#E7E9EC`（近白）。允许出现在：主按钮底、选中行左侧 2px 标记、开关开启态、分段控件选中态、Tab 下划线。禁止出现在：导航图标、表格文字、Tag、任何图标着色。

### 5.3 字体

**字体栈**

```
西文/界面：-apple-system, BlinkMacSystemFont, "Segoe UI", "Inter", "PingFang SC", "Microsoft YaHei", sans-serif
等宽：ui-monospace, SFMono-Regular, "SF Mono", Menlo, Consolas, "Liberation Mono", monospace
```

**字号阶梯**（整数化：原型中 11.5/10.5/9.5 统一收敛为 12/11/10，消除半像素，避免跨平台亚像素差异）

| Token | 字号 | 行高 | 字重 | 字距 | 使用场景 |
|---|---|---|---|---|---|
| `t-20` | 20 | 28 | 600 | -0.02em | 设置面板标题、空态主标题 |
| `t-16` | 16 | 24 | 600 | -0.015em | 对话框标题 |
| `t-13` | 13 | 20 | 600 | -0.01em | 中栏页头标题、右栏对象名、品牌名 |
| `t-12` | 12 | 18 | 500 | 0 | 列表主文本、导航项、树节点、按钮文字 |
| `t-12r` | 12 | 18 | 400 | 0 | 表格正文、输入框输入值 |
| `t-11` | 11 | 16 | 400 | 0 | 副行文本（邮箱）、KV 值、表格次要列 |
| `t-11m` | 11 | 16 | 500 | 0 | KV 值中的关键项、分段控件 |
| `t-10` | 10 | 14 | 500 | **+0.03em** | 表头、分区标题（`sec-t`）、Tag 文字 |
| `t-10r` | 10 | 14 | 400 | +0.02em | 状态栏、kbd、计数、时间戳 |

**数字规则**：所有**时间戳、计数、延迟、行数、IP、ID、SQL 片段**必须 `font-variant-numeric: tabular-nums` + 等宽字体，保证纵向对齐。正文中的普通数字不用等宽（避免视觉跳字）。

**字重只用 400 / 500 / 600**，禁止 700 及以上（粗体过重会破坏克制的层级感）。

### 5.4 间距

基础栅格 **4px**。

| Token | 值 | 用途 |
|---|---|---|
| `s-1` | 2 | 图标与文字微调、Tag 内上下 |
| `s-2` | 4 | Tag 间距、徽标组间距、行内元素间隔 |
| `s-3` | 6 | 图标与文字间距（按钮内、KV 内） |
| `s-4` | 8 | 控件内水平 padding、工具栏内间距、树项 padding |
| `s-5` | 10 | 顶栏元素间距、工具行内间距 |
| `s-6` | 12 | 单元格水平 padding、右栏区间距 |
| `s-7` | 14 | 栏内左右基准、右栏分区 padding |
| `s-8` | 16 | Toast 距边缘、区块之间 |
| `s-9` | 20 | 对话框内大区块间距 |
| `s-10` | 24 | 空态与内容边距、设置面板分组 |

半阶（6/10/14）**仅允许用于组件内部微调**，不允许作为布局级间距。

### 5.5 圆角

| 元素 | 半径 |
|---|---|
| kbd、极小 Tag | 3 |
| Tag、小图标按钮（24px）、头像小（26px） | 4 |
| Button、Input、Select、导航项、树项、分段控件、下拉项 | 5 |
| 头像大（36px）、右栏对象标识块 | 8 |
| 对话框、下拉面板、命令面板、Toast | 10 |
| **上限** | **10**（超过即违规） |
| 例外全圆 | 仅：状态点、开关轨道与滑块、头像圆形变体（不使用） |

### 5.6 边框

| Token | 值 | 场景 |
|---|---|---|
| `border-1` | `1px solid #E8E8E8` | 结构分隔：顶栏底、页头底、工具行底、表头底、栏间、右栏头/底栏、状态栏顶、输入框、按钮 |
| `border-soft` | `1px solid #F1F1F1` | 条目分隔：表格行、Inspector 分区、权限项 |
| `border-active` | `inset 0 0 0 1px #E8E8E8` + `shadow-1` | 左栏激活项（在深一档底色上「浮起」） |
| `border-selected` | `inset 2px 0 0 #18181B` | 仅表格选中行首列左侧标记 |

**全部 1px。禁止 2px/3px 边框，禁止虚线（除拖拽插入位指示线）。**

### 5.7 阴影

只有两种，能不用就不用。

| Token | 值 | 唯一用途 |
|---|---|---|
| `shadow-1` | `0 1px 2px rgba(0,0,0,.05)` | 左栏激活项「纸片浮起」、开关滑块 |
| `shadow-2` | `0 8px 24px rgba(0,0,0,.10)` + `0 0 0 1px rgba(0,0,0,.05)` | 仅浮层：下拉、命令面板、对话框、Toast |

禁止：卡片阴影、hover 抬升、按钮内阴影、彩色辉光、玻璃拟态。

### 5.8 图标

| 项 | 规范 |
|---|---|
| 风格 | **线性（stroke-only）**，24×24 viewBox，`stroke-linecap: round` |
| 线宽 | 14px 及以上用 `1.8`；12–13px 用 `2.0`；纯加号/箭头等极简符号用 `2.2` |
| 尺寸档位 | `12`（行内、KV）、`13`（按钮、树）、`14`（一级导航）、`16`（对话框头部、空态） |
| 颜色 | 继承 `currentColor`；默认随文字色（`n10`），激活态 `n11`；**图标永不着彩色** |
| 禁止 | emoji 当图标、面性/双色/填充图标、带底色徽标、旋转/抖动动画、图标 + 彩色圆底 |
| 对齐 | 图标与文字基线垂直居中；图标与文字间距固定 6–8px |

## 7. 交互规范

### 7.1 动效

| 交互 | 时长 | 曲线 | 属性 |
|---|---|---|---|
| 颜色/底色（hover、选中） | 120ms | `ease-out` | background-color, color, border-color |
| 行选中 | **0ms**（瞬时） | — | 键盘快速移动时不产生拖影 |
| 展开/折叠（树、分区） | 160ms | `cubic-bezier(.2,0,0,1)` | height / opacity |
| 开关切换 | 150ms | `ease-out` | background, transform |
| 浮层进入/退出 | 160 / 100ms | `cubic-bezier(.2,0,0,1)` | opacity, transform |
| Inspector 出现/隐去 | 120ms | `ease-out` | width / opacity |
| Toast | 160ms 进 / 120ms 出 | `ease-out` | translateY 8px + opacity |
| **禁止** | — | — | 骨架屏以外的弹跳（spring/overshoot）、超过 200ms 的界面动画、视差、背景模糊过渡 |

`prefers-reduced-motion: reduce` 下全部时长归 0，仅保留 opacity。

### 7.2 键盘快捷键

| 快捷键 | 作用 | 作用域 |
|---|---|---|
| `⌘K` / `Ctrl+K` | 打开命令面板 | 全局 |

| `⌘N` | 新建（上下文：账户 / 表 / 连接 / 会话） | 当前模块 |
| `⌘⇧N` | 新建连接 | 全局 |
| `⌘S` | 保存当前右栏编辑 | Inspector |
| `⌘F` | 聚焦工具行筛选框 | 中栏 |
| `⌘R` | 刷新当前列表 | 中栏 |
| `⌘\` | 显示/隐藏 Inspector | 全局 |
| `⌘B` | 显示/隐藏左栏 | 全局 |
| `⌘1…4` | 切换一级导航（用户/数据表/会话/审计） | 全局 |
| `⌘,` | 打开设置 | 全局 |
| `⌘↵` | 执行查询 | 查询区 |
| `⌘⇧C` | 复制选中单元格 / 选中行主字段 | 表格 |
| `↑` / `↓` | 列表中移动选中行（并同步 Inspector） | 中栏 |
| `↵` | 打开选中项（进入下一层 / 展开树） | 中栏、左栏 |
| `Space` | 切换聚焦的 Switch / Checkbox | 右栏、表格 |
| `Delete` / `⌫` | 删除选中项（触发 L2/L3 确认） | 中栏 |
| `Esc` | 关闭浮层 → 清空筛选 → 取消选择（逐级回退） | 全局 |
| `Tab` / `⇧Tab` | 焦点推进（区域内循环） | 全局 |
| `⌘Z` / `⌘⇧Z` | 撤销 / 重做（仅表单编辑与权限开关） | Inspector |

Windows 下 `⌘` 一律映射 `Ctrl`；UI 中显示的快捷键字符随平台替换（`⌘` ↔ `Ctrl`）。

### 7.3 焦点可见性

- 一律使用 `:focus-visible`，鼠标点击不显示焦点环。
- 焦点环规格：`outline: 1.5px solid #18181B; outline-offset: 2px;`（Dark 用 `#E7E9EC`）。对贴边元素（表格行、树项）改用 `inset 0 0 0 1.5px`。
- 输入类控件 focus 用边框变色 + 3px 低透明外扩，不用 outline。
- 任何 `outline: none` 都必须有替代视觉。**Tab 键走完全流程时焦点不得丢失或跳到不可见元素**。
- 焦点陷阱：Dialog / 命令面板 / Drawer 内 Tab 循环；关闭后焦点回触发源。

### 7.4 反馈机制

| 场景 | 机制 | 细节 |
|---|---|---|
| 操作成功（保存/停用/复制） | Toast | 右下 16px，320 宽，底 `n11` 文白（深色轻提示），`t-12`，3s 自动消失；带撤销则 5s 且右侧有「撤销」文字按钮 |
| 表单校验失败 | 内联 | 字段下方 11px 红字 + 输入框红边；首个错误字段自动聚焦；不弹 Toast |
| 操作失败（服务端） | 内联 + Toast | 能定位到字段则内联；否则 Toast 带 1 行原因 + 「详情」 |
| 长任务（> 1s） | 局部进度 | 按钮 loading 或表头下 2px 进度条；> 10s 显示「已用 12s · 取消」 |
| 危险操作前 | Dialog | 见 §7.5 |
| 数据被外部修改 | 顶部提示条 | 中栏顶部 28px，底 `n2`，「数据已变化 · 刷新」（避免静默覆盖） |

**禁止**：成功操作弹模态框、错误用 alert、把 Toast 放在顶部遮挡顶栏。

### 7.5 危险操作分级

| 级别 | 定义 | 例子 | 机制 |
|---|---|---|---|
| **L1 可逆** | 有撤销路径 | 停用账户、关闭连接、删除筛选条件 | 无确认；Toast + 撤销 5s |
| **L2 有副作用** | 影响多个对象或难回退 | 批量停用、重置密码、导出全表、修改权限组 | 确认对话框：标题为疑问句（「停用 3 个账户？」）、正文列出对象名（最多 5 个 + `等 3 项`）、主按钮为疑问动词、默认焦点在「取消」 |
| **L3 不可逆/高危** | 数据或身份不可恢复 | 删除账户、DROP TABLE、生产环境写操作 | 对话框 + 需**输入对象名确认**（输入框 placeholder = 对象名）+ 危险实底按钮 `#DC2626` + 默认焦点在「取消」+ 按钮在输入正确前 disabled |

**生产环境标识**：顶栏连接切换器右侧显示中性描边标签 `prod`（`tag` 变体，灰，非红色），状态栏右对齐显示「生产环境」。所有 L2/L3 对话框标题前置 `[生产]` 文字。**不使用常驻红色**，避免红色疲劳导致真实警报失效。

## 8. 主题方案

### 8.1 Light / Dark 差异规则（不是反色）

| 规则 | 说明 |
|---|---|
| R1 | **不做纯反色**：Dark 不用 `#000` 底、不用 `#FFF` 字。Light `#FFF` → Dark `#101013`；Light `#18181B` 字 → Dark `#E7E9EC` |
| R2 | **层级方向反转**：Light 用「越深越强调」，Dark 用「越亮越强调」。Light 中 `n1/n2`（抬高面）比底色深；Dark 中抬高面比底色**亮** |
| R3 | **边框对比度下调**：Light 边框与底差 ~8%（`#E8E8E8` vs `#FFF`）；Dark 只差 ~5%，避免深色下网格线「发光」 |
| R4 | **语义色降饱和 8–12%**：`#16A34A` → `#34C06A`；`#DC2626` → `#E5484D`；`#D97706` → `#E39A3B`，保证深底可读 |
| R5 | **阴影换成描边**：Dark 下 `shadow-2` 的黑色阴影不可见，改为 `0 0 0 1px rgba(255,255,255,.08)` + 极弱黑阴影 |
| R6 | **强调色反相**：Light 主按钮黑底白字；Dark 主按钮白底黑字（不是同一色相） |
| R7 | **图片/等宽块不反色**：SQL 编辑器与终端固定深色，不随主题变 |

### 8.2 两套 token 对照（关键项）

| Token | Light | Dark |
|---|---|---|
| `bg`（画布） | `#FFFFFF` | `#101013` |
| `bg-sub`（次级面） | `#FAFAFA` | `#151518` |
| `bg-hover` | `#F4F4F5` | `#1D1D21` |
| `bg-solid`（Tag 实心/头像） | `#EFEFF1` | `#24242A` |
| `line`（主边框） | `#E8E8E8` | `#26262B` |
| `line-soft`（次边框） | `#F1F1F1` | `#1E1E22` |
| `t1`（一级文字） | `#18181B` | `#E7E9EC` |
| `t2`（二级文字） | `#52525B` | `#A9AEB8` |
| `t3`（三级文字） | `#8E8E96` | `#7E838D` |
| `t4`（四级文字） | `#A8A8B0` | `#61666F` |
| `accent` | `#18181B` | `#E7E9EC` |
| 主按钮底/字 | `#18181B` / `#FFF` | `#E7E9EC` / `#101013` |
| `success` | `#16A34A` | `#34C06A` |
| `danger` | `#B91C1C` / `#DC2626` | `#F07178` / `#E5484D` |

### 8.3 切换与持久化

| 项 | 规范 |
|---|---|
| 入口 | 设置 → 外观 → 配色方案（三段控件：浅色 / 深色 / 跟随系统） |
| 快捷 | 命令面板搜索「切换主题」 |
| 持久化 | `localStorage['dbnest.theme']`，值 `light \| dark \| system`，默认 `system` |
| 生效 | 根元素 `data-theme` 属性 + CSS 变量；切换无闪烁（先写属性再渲染，禁止先亮后暗） |
| 系统跟随 | `matchMedia('(prefers-color-scheme: dark)')` 监听变化，仅在 `system` 下生效 |
| 过渡 | **不做全局颜色过渡动画**（会卡顿）；仅控件自身 120ms |
| 现状处置 | 现有 `dracula` / `glass` 主题：`dracula` 并入 dark 的配色变体（保留编辑器配色），`glass` 建议下线（见 §11） |

## 10. 设计红线（Do / Don't）

| # | ✅ Do | ❌ Don't |
|---|---|---|
| 1 | 用 6px 状态点 + 灰色文字表达「启用/停用」 | 用绿色/红色胶囊标签写「启用」 |
| 2 | 分区靠 1px `#F1F1F1` 细线划分 | 用彩色左侧竖条、卡片投影、色块分区 |
| 3 | 主按钮用近黑实底（`#18181B`），一屏一个 | 用蓝/紫渐变按钮，或满屏都是实底按钮 |
| 4 | 圆角最大 10px，按钮/输入 5px | 用 12–16px 大圆角、半圆胶囊按钮 |
| 5 | 阴影只给浮层，且极弱 | 给卡片、按钮、hover 行加阴影做「浮起」 |
| 6 | 图标用 Lucide 线性 1.8 线宽，继承文字色 | 用 emoji 当图标、彩色图标、图标加渐变圆底 |
| 7 | 表格用固定表头 + 单行省略号 + hover 全文 | 用斑马纹、竖线分栏、行间大留白 |
| 8 | 数字/时间/ID 用 tabular-nums 等宽 | 表格里时间左右参差、数字用比例字体 |
| 9 | 元信息用 10–11px 灰字，字号阶梯 6 档 | 用 9px 以下字号、或一屏出现 5 种以上字号 |
| 10 | 批量操作在工具行原位替换 | 弹一条浮动的蓝色批量操作条遮住内容 |
| 11 | 空状态说明「下一步做什么」+ 一个按钮 | 只放一个灰字「暂无数据」 |
| 12 | 危险操作按 L1/L2/L3 分级加摩擦 | 所有删除都弹窗，或都不弹窗 |
| 13 | 生产环境用灰色 `prod` 标签 + 文案提示 | 顶栏常驻红色横幅/红色边框（红色疲劳） |
| 14 | 悬停只改背景色（120ms） | 悬停放大、位移、发光、光标变手型 |
| 15 | 选中行靠底色 + 左侧 2px 黑条 | 选中行用蓝色高亮 + 白色文字 |

## 11. 待确认问题

| # | 问题 | 影响 | 建议方案 |
|---|---|---|---|
| Q1 | 现有 `dracula` / `glass` 两套主题是否下线？`glass` 含背景模糊与半透明，与本规范「无玻璃拟态」冲突 | §8 主题体系、设置面板文案、老用户预期 | 建议：`dracula` 保留为「深色（Darcula）」配色变体，仅换 token 不换布局；`glass` 下线，迁移时提示并落回 dark |
